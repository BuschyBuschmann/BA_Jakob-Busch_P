English version first, für die deutsche Version nach unten scrollen.

Installation:
copy libmaiv2dll.so to /usr/lib/

Prerequisites:
libmaiv2dll.so depends on libusb-1.0.0.so (open source)


the libusb-1.0.0.so binary is available by installing:

	sudo apt-get install libusb-1.0-0
	
	

you can also compile it yourself form sourcecode:

http://www.libusb.org/
direct link: http://sourceforge.net/projects/libusb/files/libusb-1.0/libusb-1.0.9/libusb-1.0.9.tar.bz2

or use the replacement libusbx:

http://libusbx.org/
direct link: http://netcologne.dl.sourceforge.net/project/libusb/libusb-1.0/libusb-1.0.18/libusb-1.0.18.tar.bz2


the API documentation is only available as a Windows chm file at the moment.
You can view chm files with the freeware tools chmsee and kchmviewer
http://chmsee.gro.clinux.org/
http://www.kchmviewer.net/


or with firefox using the chm-reader add-on:
https://addons.mozilla.org/de/firefox/addon/chm-reader/

Und nun nochmal auf Deutsch:

kopieren Sie  libmaiv2dll.so nach /usr/lib/

Voraussetzungen:
libmaiv2dll.so benötigt  libusb-1.0.0.so (open source) zum Betrieb.


Die Binärdatei libusb-1.0.0.so Sie können sie so direkt installieren:

http://www.libusb.org/

wahlweise können Sie auch libusbx verwenden:

http://libusbx.org/
