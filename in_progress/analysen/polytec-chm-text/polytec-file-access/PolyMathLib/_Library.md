# PolyMathLib – _Library

## Project Overview

*Quelle: `PolyMathLib_P.html` · Polytec PolyMath Type Library*

### Description

Polytec PolyMath is a collection of objects exposing methods to conveniently perform mathematical operations. All input arrays are treated as if they were zero based. All output arrays are zero based.

### Classes

| Class Module | Description |
|---|---|
| DataPeak | A peak found by the peak finder. |
| DataPeaks | The data peaks found by the peak finder. |
| GeometryProcessing | GeometryProcessing contains methods for processing geometry, e.g. calculating surface normals. |
| PeakFinder | The peak finder allows to find peaks in a data array. |
| PeakFit | PeakFit allows to fit the frequency response of a one-dimensional harmonic oscillator to a real or complex spectrum. |
| SignalProcessing | SignalProcessing contains methods performing signal processing operations on one dimensional arrays of Single or Double, interpreted as real or complex vectors. |
| Statistics | Statistics contains methods performing basic statistics operations on one dimensional arrays of Single or Double, interpreted as real vectors. |
| Transform3DProcessing | Provides a transformation from one Cartesian 3D coordinate system to another. |
| Vector | Vector contains methods performing basic mathematical operations on one dimensional arrays of Single or Double, interpreted as real or complex vectors. |
