# PolyFrontEndLib – PTCFrontEndCapsType

## PTCFrontEndCapsType Enumeration

*Quelle: `PolyFrontEndLib~PTCFrontEndCapsType.html` · Polytec PolyFrontEnd Type Library*

### Description

The front-end capabilities.

### Members

| Member | Value | Description |
|---|---|---|
| ptcFrontEndCaps3D | 4 | The front-end is a PSV-3D front-end. |
| ptcFrontEndCapsControllable | 1 | The front-end is controllable. |
| ptcFrontEndCapsDCCouplingForVibChannels | 1024 | The vibrometer channels of the front-end have always DC coupling. |
| ptcFrontEndCapsDifferentialInput | 2 | The front-end has differential input. |
| ptcFrontEndCapsDigitalVideo | 4096 | The front-end has digital video capability. |
| ptcFrontEndCapsFixedVibChannels | 256 | The front-end provides vibrometer channels. |
| ptcFrontEndCapsFringeCounter | 32 | The front-end has fringe counter capability. |
| ptcFrontEndCapsIEPEEnforceACCoupling | 2048 | The IEPE setting enforces AC coupling when activated for a channel. |
| ptcFrontEndCapsIOFrontEnd | 128 | The front-end used the Polytec.IO.FrontEnd software component for communication. |
| ptcFrontEndCapsMultipleScanHead | 8 | The front-end is multiple scan head front-end. |
| ptcFrontEndCapsMultiPointVib | 8192 | The front-end is a multipoint vibrometer front-end. |
| ptcFrontEndCapsNoHWDecoder | 16384 | The front-end has no hardware decoder. |
| ptcFrontEndCapsReferenceChannels | 512 | The front-end has reference channels. |
| ptcFrontEndCapsSinglePoint3D | 32768 | The front-end is a 3D or 3D (1D) single point front-end, e.g. VFX-F-110 or VGO-200 |
| ptcFrontEndCapsSVideo | 64 | The front-end has S-Video capability. |
| ptcFrontEndCapsVDD | 16 | The front-end has digital demodulation (VDD) capability. |
