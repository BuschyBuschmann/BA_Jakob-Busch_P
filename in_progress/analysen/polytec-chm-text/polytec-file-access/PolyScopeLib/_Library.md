### Description

The Polytec PolyScope type library contains definitions for the acquisition state, input coupling of the channels and the trigger.

### Public Enumerations

| Enumeration | Description |
|---|---|
| PTCInputCoupling | The input coupling of the channel. |
| PTCTriggerEdge | The edge for trigger detection. |
| PTCTriggerSource | The source for the trigger. |
