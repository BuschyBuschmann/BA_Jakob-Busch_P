# _Konzept – Type Libraries Overview

## Type Libraries Overview

*Quelle: `Type Libraries Overview.html` · Object Model Reference*

#### Type Libraries Overview

The object model is separated into the type libraries listed in the table of contents below this topic. For every element described in the documentation you will find the corresponding type library listed in the header of the page. Most development environments add automatically references to dependent type libraries when adding the root type library. If this is not the case, you have to add the references manually.

Please use the PolyFile Object as an entry point into the object model.
