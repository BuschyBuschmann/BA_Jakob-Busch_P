# POLYPROPERTIESLib – PTCScanRangeStyle

## PTCScanRangeStyle Enumeration

*Quelle: `POLYPROPERTIESLib~PTCScanRangeStyle.html` · Polytec PolyProperties Type Library*

### Description

The style for displaying the scan range in the 3D view.

### Members

| Member | Value | Description |
|---|---|---|
| ptcScanRangeStyleAll | 2 | Display all scan ranges. |
| ptcScanRangeStyleNone | 0 | Display no scan range. |
| ptcScanRangeStyleSelected | 1 | Display the scan ranges for the selected points, only. |
