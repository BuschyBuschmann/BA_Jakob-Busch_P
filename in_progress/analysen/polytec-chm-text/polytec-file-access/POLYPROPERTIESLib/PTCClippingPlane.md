# POLYPROPERTIESLib – PTCClippingPlane

## PTCClippingPlane Enumeration

*Quelle: `POLYPROPERTIESLib~PTCClippingPlane.html` · Polytec PolyProperties Type Library*

### Description

The supported clipping planes for a clipping of the geometry in the 3D view.

### Members

| Member | Value | Description |
|---|---|---|
| ptcClippingPlaneFar | 7 | The back clipping plane perpendicular to the view direction of the virtual camera. |
| ptcClippingPlaneMaxX | 1 | The clipping plane oriented towards bigger x-coordinates and perpendicular to the x-axis. |
| ptcClippingPlaneMaxY | 3 | The clipping plane oriented towards bigger y-coordinates and perpendicular to the y-axis. |
| ptcClippingPlaneMaxZ | 5 | The clipping plane oriented towards bigger z-coordinates and perpendicular to the z-axis. |
| ptcClippingPlaneMinX | 0 | The clipping plane oriented towards lower x-coordinates and perpendicular to the x-axis. |
| ptcClippingPlaneMinY | 2 | The clipping plane oriented towards lower y-coordinates and perpendicular to the y-axis. |
| ptcClippingPlaneMinZ | 4 | The clipping plane oriented towards lower z-coordinates and perpendicular to the z-axis. |
| ptcClippingPlaneNear | 6 | The front clipping plane perpendicular to the view direction of the virtual camera. |
