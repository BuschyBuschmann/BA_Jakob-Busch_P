# POLYPROPERTIESLib – PTCWindowState

## PTCWindowState Enumeration

*Quelle: `POLYPROPERTIESLib~PTCWindowState.html` · Polytec PolyProperties Type Library*

### Description

The state of the application window.

### Members

| Member | Value | Description |
|---|---|---|
| ptcWindowStateMaximize | 0 | The window is maximized. |
| ptcWindowStateMinimize | 1 | The window is minimized. |
| ptcWindowStateNormal | 2 | The window is neither maximized nor minimized. |
