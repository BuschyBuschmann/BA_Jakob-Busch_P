# POLYWAVEFORMSLib – WaveformSimple

## WaveformSimple Object

*Quelle: `POLYWAVEFORMSLib~WaveformSimple.html` · Polytec PolyWaveforms Type Library*

### Description

Waveform simple is the base object of the objects WaveformSine, WaveformSquare, WaveformTriangle,WaveformRamp, WaveformUserDefined Object.

### Remarks

You cannot create a waveform object directly. Create an object of one of the derived objects instead.
