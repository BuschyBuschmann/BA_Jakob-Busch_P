# POLYWAVEFORMSLib – IWaveform

## IWaveform Interface

*Quelle: `POLYWAVEFORMSLib~IWaveform.html` · Polytec PolyWaveforms Type Library*

### Description

Waveform is the base object of the objects WaveformBurstChirp, WaveformBurstRandom, WaveformMultiCarrierCW Object, WaveformPeriodicChirp, WaveformPseudoRandom, WaveformRamp, WaveformSimple, WaveformSine, WaveformSquare, WaveformSteppedSineSweep, WaveformSweep, WaveformTriangle, WaveformUserDefined and WaveformWhiteNoise

### Remarks

It is recommended to cast to the Waveform object.
