# Polytec_IO_VibInterfaces – SensorHeadCaps2

## SensorHeadCaps2 Enumeration

*Quelle: `Polytec_IO_VibInterfaces~SensorHeadCaps2.html` · Polytec IO VibInterfaces Type Library*

### Description

The extended capabilities of the sensor head.

### Members

| Member | Value | Description |
|---|---|---|
| SensorHeadCaps2_DifferentialMeasurementMode | 128 | The sensor head supports the differential measurement mode, e.g. on MSA-600 systems. |
| SensorHeadCaps2_ExternalScannerControl | 256 | The sensor head supports external control of the scanners. |
| SensorHeadCaps2_LaserPower | 64 | The sensor head provides information about the nominal laser power. |
| SensorHeadCaps2_LaserPowerSupply | 512 | The sensor head has a laser power supply and supports switching the power supply on or off. |
| SensorHeadCaps2_LaserTemperature | 1 | The sensor head provides information about the laser temperature. |
| SensorHeadCaps2_LaserTemperatureOutOfRange | 2 | The sensor head provides information about whether the laser temperature is out of range. |
| SensorHeadCaps2_None | 0 | None of the capabilities is available. |
| SensorHeadCaps2_QTec | 1024 | The sensor head supports QTec. |
| SensorHeadCaps2_RGBLedColor | 32 | The sensor head has a status LED with RGB color. |
| SensorHeadCaps2_RSSILevelBlink | 16 | The sensor head supports the RSSI level blinking, where the signal level value is indicated by the blinking frequency of the status LED. |
| SensorHeadCaps2_Sonde | 4 | The sensor head is a sonde. |
| SensorHeadCaps2_UniqueID | 8 | The sensor head provides a unique identifier. |
