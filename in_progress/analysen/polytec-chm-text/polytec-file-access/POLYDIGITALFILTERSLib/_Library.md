# POLYDIGITALFILTERSLib – _Library

## Project Overview

*Quelle: `POLYDIGITALFILTERSLib_P.html` · Polytec PolyDigitalFilters Type Library*

### Description

The Polytec PolyDigitalFilters type library contains objects that give access to the digital filters defined for data acquisition channels in MPV/PSV/VibSoft and allow to modify the data acquisition settings for these channels by selecting different filters or changing the parameters of the filters.

### Classes

| Class Module | Description |
|---|---|
| DigitalFilter | Base object of DigitalFilterLowpass , DigitalFilterHighpass , DigitalFilterBandpass , DigitalFilterNotch and DigitalFilterNone . |
| DigitalFilterBandpass | A band pass digital filter. |
| DigitalFilterHighpass | A high pass digital filter. |
| DigitalFilterLowpass | A low pass digital filter. |
| DigitalFilterNone | Represents the fact, that no digital filter is set. |
| DigitalFilterNotch | A notch digital filter. |

### Interfaces

| IDigitalFilter | Base object of DigitalFilterLowpass , DigitalFilterHighpass , DigitalFilterBandpass , DigitalFilterNotch and DigitalFilterNone . |
