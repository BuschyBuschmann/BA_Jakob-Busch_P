# PolyScanHeadLib – ZStageSettings

## ZStageSettings Object

*Quelle: `PolyScanHeadLib~ZStageSettings.html` · Polytec PolyScanHead Type Library*

### Description

The properties of the z-stage of the MSA-500 system used for focusing the laser beam and measuring distances.


---

## ZStageSettings Object Members

*Quelle: `PolyScanHeadLib~ZStageSettings_members.html` · Polytec PolyScanHead Type Library*

### Public Properties

| Delay | Specifies the delay before the focusing in second. |
|---|---|
| Duration | Specifies the duration of the focusing excluding the delay before the start. |
| Max | Specifies the highest possible position of the z-stage in meter. |
| Min | Specifies the lowest possible position of the z-stage in meter. |
