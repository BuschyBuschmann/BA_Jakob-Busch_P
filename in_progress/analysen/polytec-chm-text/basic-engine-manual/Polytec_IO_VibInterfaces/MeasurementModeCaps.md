# Polytec_IO_VibInterfaces – MeasurementModeCaps

## MeasurementModeCaps Enumeration

*Quelle: `Polytec_IO_VibInterfaces~MeasurementModeCaps.html` · Polytec IO VibInterfaces Type Library*

### Description

The capabilities of the measurement mode.

### Members

| Member | Value | Description |
|---|---|---|
| MeasurementModeCaps_None | 0 | The measurement mode has no capabilities. |
| MeasurementModeCaps_Rotation | 2 | The measurement mode can be rotation. |
| MeasurementModeCaps_Translation | 1 | The measurement mode can be translation. |

### Remarks

Measurement modes other then none are used to specify the measurement mode for the RLV-5000 controller.
