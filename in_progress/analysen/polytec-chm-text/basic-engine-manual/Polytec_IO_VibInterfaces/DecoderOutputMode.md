# Polytec_IO_VibInterfaces – DecoderOutputMode

## DecoderOutputMode Enumeration

*Quelle: `Polytec_IO_VibInterfaces~DecoderOutputMode.html` · Polytec IO VibInterfaces Type Library*

### Description

The output mode of the decoder.

### Members

| Member | Value | Description |
|---|---|---|
| DecoderOutputMode_Analog | 0 | The analog output of the decoder is enabled. |
| DecoderOutputMode_AnalogAndDigital | 2 | The analog and digital output of the decoder is enabled. |
| DecoderOutputMode_Digital | 1 | The digital output of the decoder is enabled. |
