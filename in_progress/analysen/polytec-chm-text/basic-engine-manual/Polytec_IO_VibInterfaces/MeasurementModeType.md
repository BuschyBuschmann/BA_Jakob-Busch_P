# Polytec_IO_VibInterfaces – MeasurementModeType

## MeasurementModeType Enumeration

*Quelle: `Polytec_IO_VibInterfaces~MeasurementModeType.html` · Polytec IO VibInterfaces Type Library*

### Description

The measurement mode of the controller.

### Members

| Member | Value | Description |
|---|---|---|
| MeasurementModeType_Rotation | 1 | The measurement mode is rotation. |
| MeasurementModeType_Translation | 0 | The measurement mode is translation. |

### Remarks

Measurement modes other then none are used to specify the measurement mode for the RLV-5000 controller.
