# Polytec_IO_VibInterfaces – ConnectionMode

## ConnectionMode Enumeration

*Quelle: `Polytec_IO_VibInterfaces~ConnectionMode.html` · Polytec IO VibInterfaces Type Library*

### Description

The connection mode.

### Members

| Member | Value | Description |
|---|---|---|
| ConnectionMode_None | 0 | The connection mode is none. |
| ConnectionMode_Rotation | 2 | The connection mode is rotation. |
| ConnectionMode_Translation | 1 | The connection mode is translation. |

### Remarks

The connection modes other then none are used to specify the measurement mode for the RLV-5000 controller.
