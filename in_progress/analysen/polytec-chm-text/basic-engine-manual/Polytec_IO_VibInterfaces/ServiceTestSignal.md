*Quelle: `Polytec_IO_VibInterfaces~ServiceTestSignal.html` · Polytec IO VibInterfaces Type Library*

### Description

The state of the service mode test signal.

### Members

| Member | Value | Description |
|---|---|---|
| ServiceTestSignal_Fullscale | 2 | The test signal is sinusoidal with a full scale amplitude. |
| ServiceTestSignal_Off | 0 | The test signal is off. |
| ServiceTestSignal_Zero | 1 | The test signal has an amplitude of 0 V. |
