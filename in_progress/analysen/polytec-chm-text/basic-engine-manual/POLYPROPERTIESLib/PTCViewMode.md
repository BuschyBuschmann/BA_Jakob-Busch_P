# POLYPROPERTIESLib – PTCViewMode

## PTCViewMode Enumeration

*Quelle: `POLYPROPERTIESLib~PTCViewMode.html` · Polytec PolyProperties Type Library*

### Description

The view mode of the area view.

### Members

| Member | Value | Description |
|---|---|---|
| ptcViewModeAverage | 2 | The view mode is band area data for the object and an analyzer for point average data. |
| ptcViewModeObject | 0 | The view mode is band area data for the object only. |
| ptcViewModePointAverage | 6 | The view mode is point area data and an analyzer for point average data. |
| ptcViewModePointObject | 4 | The view mode is point area data for the object only. |
| ptcViewModePointProfile | 7 | The view mode is point area data and an analyzer for profiles. |
| ptcViewModePointSinglePoint | 5 | The view mode is point area data and an analyzer for single point data. |
| ptcViewModeProfile | 3 | The view mode is band area data for the object and an analyzer for profiles. |
| ptcViewModeSinglePoint | 1 | The view mode is band area data for the object and an analyzer for single point data. |

### Remarks

The view modes for point area data activate cursor mode.
