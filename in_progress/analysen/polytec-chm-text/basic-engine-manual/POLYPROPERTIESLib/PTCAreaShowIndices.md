# POLYPROPERTIESLib – PTCAreaShowIndices

## PTCAreaShowIndices Enumeration

*Quelle: `POLYPROPERTIESLib~PTCAreaShowIndices.html` · Polytec PolyProperties Type Library*

### Description

Specifies whether the labels (displayed indices) of the scan points are shown.

### Members

| Member | Value | Description |
|---|---|---|
| ptcAreaShowIndicesAll | 1 | All indices are shown. |
| ptcAreaShowIndicesNone | 0 | No indices are shown. |
| ptcAreaShowIndicesSelected | 2 | The indices are shown for selected points. |
