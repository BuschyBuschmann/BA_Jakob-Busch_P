# POLYWAVEFORMSLib – WaveformMultiCarrierCW

## WaveformMultiCarrierCW Object

*Quelle: `POLYWAVEFORMSLib~WaveformMultiCarrierCW.html` · Polytec PolyWaveforms Type Library*

### Description

The multi-carrier-CW waveform of the SMBV100A/B signal generator of PSV-UHF, VibSoft-UHF, MSA-600-U and some MSA-600-S systems.

### Remarks

This class can be instantiated using the string "PolyWaveforms.WaveformMultiCarrierCW".
