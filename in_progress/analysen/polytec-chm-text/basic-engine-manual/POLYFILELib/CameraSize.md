# POLYFILELib – CameraSize

## CameraSize Object

*Quelle: `POLYFILELib~CameraSize.html` · Polytec PolyFile Type Library*

### Description

Size of a camera chip used for objective calibrations.

### Remarks

This class can be instantiated using the string "PolyFile.CameraSize".

Beginning with the software releases in July 2018, a "lens" is called "objective" in the GUI of the applications.
