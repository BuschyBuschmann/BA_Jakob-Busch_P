# POLYFILELib – PTCMeasurementLocationMode

## PTCMeasurementLocationMode Enumeration

*Quelle: `POLYFILELib~PTCMeasurementLocationMode.html` · Polytec PolyFile Type Library*

### Description

The possible measurement location modes.

### Members

| Member | Value | Description |
|---|---|---|
| ptcMeasurementLocationModeFixed | 0 | In this mode a MeasurementLocation object contains a measurement direction and a normal for at most a single scan point. |
| ptcMeasurementLocationModeVarying | 1 | In this mode a MeasurementLocation object contains measurement directions and normals for several scan points. |

### Remarks

ptcMeasurementLocationModeFixed is the default value, ptcMeasurementLocationModeVarying is currently not in use.
