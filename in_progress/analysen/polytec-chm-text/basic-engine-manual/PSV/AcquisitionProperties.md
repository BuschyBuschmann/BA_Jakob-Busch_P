# PSV – AcquisitionProperties

## AcquisitionProperties Collection

*Quelle: `PSV~AcquisitionProperties.html` · Polytec PSV Type Library*

### Description

A typed collection of objects representing the respective acquisition properties.

### Remarks

Depending on the acquisition mode (see Acquisition.Mode) this collection contains different objects.
