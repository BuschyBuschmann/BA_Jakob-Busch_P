# PSV – PTCAssignFocusAutomaticallyCaps

## PTCAssignFocusAutomaticallyCaps Enumeration

*Quelle: `PSV~PTCAssignFocusAutomaticallyCaps.html` · Polytec PSV Type Library*

### Description

Specifies how the software executes the assign focus values automatically command.

### Members

| Member | Value | Description |
|---|---|---|
| ptcAssignFocusAutomaticallyCapsNone | 0 | The focus values are determined from and assigned to all scan points. |
| ptcAssignFocusAutomaticallyCapsSelected | 1 | The focus values are determined from and assigned to the selected scan points, only. |
