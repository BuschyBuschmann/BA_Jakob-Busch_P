# PSV – PTCPrintOptions

## PTCPrintOptions Enumeration

*Quelle: `PSV~PTCPrintOptions.html` · Polytec PSV Type Library*

### Description

The printing options.

### Members

| Member | Value | Description |
|---|---|---|
| ptcPrintLower | 4 | Print the lower pane of the window. |
| ptcPrintNoUserPrompt | 1 | Do not prompt the user. |
| ptcPrintUpper | 2 | Print the upper pane of the window. |

### Remarks

The values can be combined, e.g. to print the upper and lower pane of the window.
