# _Konzept – Opening and Closing Files

## Opening and Closing Files

*Quelle: `Opening and Closing Files.html` · Basic Engine Manual · The PSV/VibSoft Object Model > Opening and Closing Files*

To access data stored in PSV or VibSoft files you can use Polytec File Access.

After creating a PolyFile object by

*Instantiating PolyFile:*
```
Dim oFile As PolyFile
Set oFile = New PolyFile
```

you can open any measurement or settings file generated by PSV (Version 7.0 or higher) or VibSoft (Version 3.0 or higher) by using the Open method of PolyFile.

You can create any number of PolyFile objects but you can open only a single file per PolyFile object. You cannot open a file more than once at the same time (by Polytec File Access or by scripting PolyFile or by PSV/VibSoft) because this results in a sharing violation.

Deleting the PolyFile object automatically closes the file. You have to close the file before you can open another file using the same PolyFile object by using the Close method.
