# POLYALIGNMENTLib – _Library

## Project Overview

*Quelle: `POLYALIGNMENTLib_P.html` · Polytec PolyAlignment Type Library*

### Description

The Polytec PolyAlignment type library contains objects that represent the 2D and 3D alignments available in the MPV/PSV software. With these objects you can access information about the existing alignments, transform coordinates using the alignments and modify existing or calculate new alignments.
