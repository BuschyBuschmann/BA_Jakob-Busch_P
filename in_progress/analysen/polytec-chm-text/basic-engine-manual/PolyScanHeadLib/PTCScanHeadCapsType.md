# PolyScanHeadLib – PTCScanHeadCapsType

## PTCScanHeadCapsType Enumeration

*Quelle: `PolyScanHeadLib~PTCScanHeadCapsType.html` · Polytec PolyScanHead Type Library*

### Description

The scanning head capabilities.

### Members

| Member | Value | Description |
|---|---|---|
| ptcScanHeadCaps3HeadsInOne | 2048 | Scanning head has three optical sensors (e.g. MSA-I-100) |
| ptcScanHeadCapsControl | 1 | Scanning head is controllable. |
| ptcScanHeadCapsDisplay | 256 | Scanning head has a display for full screen live video. |
| ptcScanHeadCapsDistanceSensor | 64 | Scanning head can be used with distance sensor. |
| ptcScanHeadCapsGreenLaser | 8192 | Scanning head has a green laser (e.g. UHF) |
| ptcScanHeadCapsHandSet | 4 | Scanning head can be used with handset. |
| ptcScanHeadCapsLaserAutoFocus | 32 | Scanning head has laser autofocus. |
| ptcScanHeadCapsLaserControl | 512 | Scanning head can move the laser beam. |
| ptcScanHeadCapsLaserFocus | 16 | Scanning head has laser focus. |
| ptcScanHeadCapsMicroscopic | 128 | Scanning head belongs to a microscope scanning vibrometer (e.g. MSA-500). |
| ptcScanHeadCapsMultipleLenses | 4096 | Scanning head has multiple objectives for a microscope scanning vibrometer. |
| ptcScanHeadCapsNone | 0 | Scanning head has no capabilities. |
| ptcScanHeadCapsPanTilt | 8 | Scanning head can be used with pan-tilt head. |
| ptcScanHeadCapsScannerControl | 1024 | Scanning head controls the scanners. |
| ptcScanHeadCapsSpeckleTracking | 16384 | Scanning head supports speckle tracking. |
| ptcScanHeadCapsVideo | 2 | Scanning head has video camera. |

### Remarks

Beginning with the software releases in July 2018, a "lens" is called "objective" in the GUI of the applications.
